# 审批管理

## 入口与范围

管理后台通过“工作台 → 审批管理”进入，地址为 `/admin/approvals`。
个人待办仍使用 `/app/approvals`。后台查看权限不等于审批资格。

后台聚合技能本地审核、技能钉钉审批，以及包含人工审批节点的工作流实例。
技能按审核请求展示，工作流按实例展示，不按候选审批人重复列出。
纯 Agent 工作流、MCP 门禁和设备上的本地 Runtime 审批不在此列表中。

## 查看与筛选

- 可按视图、类型、渠道、状态、关键词、发起人 ID 和日期筛选。
- 选择技能类型后可按空间 ID 筛选；选择工作流类型后可按模板 ID 筛选。
- 结束日期包含当天，统计使用与列表一致的筛选和权限范围，不受当前分页影响。
- “查看详情”打开抽屉；“打开详情页”提供独立地址，返回时保留列表筛选。
- 详情展示本轮审核进度、评分、处理意见或工作流节点记录；工作流操作记录包含操作者、时间及终止原因。
- 技能材料和下载绑定本次请求。已失效、空间变化或内容不一致的轮次仅展示可授权的审批记录，不再提供材料。

## 权限与操作

| 能力 | 条件 |
|---|---|
| 查看技能审批 | `console:skill:read`，并有原审批空间及技能当前空间的读取授权 |
| 查看工作流审批 | `console:workflow:instance_read`，沿用全部实例管理范围 |
| 处理审批 | 当前账号是有效待审批人，进入个人审批页按原规则处理 |
| 终止工作流 | `console:workflow:instance_terminate`，实例仍运行；必须填写原因并确认 |
| 同步钉钉结果 | `console:skill:publish`，钉钉已配置，且是当前有效、运行中的外部实例 |
| 核对异常实例 | 同上，外部提交处于“提交中”或“状态待核对”；绑定已有实例或明确确认未创建 |

拥有任一领域的查看权限即可进入页面，但列表、统计、详情和材料都独立执行后端授权。
未配置钉钉时仍可查看记录，不显示不可执行的外部管理操作。
管理台不提供强制通过、批量审批、审批转交、催办或重开。

## 接口

- `GET /api/v1/admin/approvals`：权限过滤后的混合游标分页。
- `GET /api/v1/admin/approvals/summary`：当前筛选范围的统计。
- `GET /api/v1/admin/approvals/:kind/:id`：审批详情与当前可用操作。
- 技能材料使用上述详情路径下的 `/files`、`/file?path=...` 和 `/package`。

`kind` 为 `skill`、`skill_external` 或 `workflow_instance`。
同步、核对及终止复用既有领域接口；没有新增管理员审批决定接口。
