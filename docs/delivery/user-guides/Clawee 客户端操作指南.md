# Clawee 客户端操作指南

适用对象：第一次使用 Clawee 桌面客户端的普通成员。更新日期：2026 年 10 月 26 日。

先按第 1、2 节完成首次配置和第一个任务，再按需查看后续操作。菜单名称、资源和可用功能以你的账号权限为准。

## 1. 下载、登录与首次配置

### 1.1 下载并安装

打开部署者提供的客户端下载页，例如 `https://gateway.example.com/downloads`（示例地址须替换），选择与你的电脑匹配的安装包，点击“下载安装包”。

| 你的电脑 | 下载选择 |
| --- | --- |
| 使用 M 系列芯片的 Mac | macOS Apple Silicon |
| 使用 Intel 芯片的 Mac | macOS Intel |
| Windows 电脑 | Windows |

Mac 可在苹果菜单 →“关于本机”查看芯片。下载完成后，Mac 打开安装包并将 Clawee 放入“应用程序”；Windows 按安装向导完成安装。随后打开 Clawee。版本以下载页面当前提供的稳定版为准。

### 1.2 连接服务器，用钉钉扫码登录

1. 在登录页检查“服务器”。没有目标地址时，选择“添加服务器”，填写部署者提供的 Gateway 地址并保存，例如 `https://gateway.example.com`；已有地址时直接选中。
2. 无需填写账号密码。阅读并勾选同意服务协议与隐私政策，点击“钉钉登录”。
3. 在自动打开的系统浏览器中，用手机钉钉扫码，按手机提示确认授权。
4. 返回 Clawee，等待登录完成。若仍显示“等待钉钉授权”，先确认已在浏览器中完成授权。

**服务器地址：** 使用部署者提供的 Gateway 地址，例如 `https://gateway.example.com`（示例地址须替换）。

**注意：此处填写企业服务器地址；模型 Base URL 在第 1.3 节单独填写，两个地址不能混用。**



**完成标志：** 进入模型配置页或工作界面。模型 API Key 由管理员另行提供。

<div style="page-break-before: always;"></div>

### 1.3 配置模型服务

首次出现模型配置页时按下表填写；已能正常发送任务可直接进入第 2 节。

**特别提醒：Base URL 是模型服务地址，与登录页的“服务器”地址不同，不能填成企业服务器地址。**

| 界面字段 | 填写内容 |
| --- | --- |
| Base URL | 管理员提供的模型服务地址，例如 `https://models.example.com/v1`（示例地址须替换） |
| Model／模型名字 | 模型服务提供的可用模型 ID |
| API Key | 管理员分配给你的模型 API Key |

1. 填写管理员提供的实际地址和模型名称，注意保留地址末尾的 `/v1`。
2. 填入自己的 API Key，点击“保存并启动 Clawee”。密钥默认以圆点显示。
3. 进入工作界面后，确认输入区显示配置的模型名称。
4. 需要检查或修改时，点击左下角齿轮 →“AI模型配置”，核对后点击“检测模型”；修改内容后点击“保存配置”。检测和保存是两个操作。



**注意：** API Key 不要发到会话或截图中。遇到问题请联系管理员。

### 1.4 认识工作界面

- **“新建会话”与“项目”**：开始任务、选择资料所在的本机文件夹。
- **会话区与输入框**：描述要求、查看过程、补充意见；“最近会话”用于找回任务，切换会话不会停止执行。
- **企业Skill、知识库、网盘**：按需使用已授权能力；工作台、工作流、定时任务的操作见后文。

**完成标志：** 已进入工作界面，能选择项目，输入框可用，并显示配置的模型名称。

## 2. 完成第一个任务：把示例反馈整理成报告

本练习无需提前准备文件。直接复制下方的 6 条模拟客户反馈，让 Clawee 生成一份报告。

### 2.1 添加项目并发起会话

1. 先在电脑上新建一个空文件夹；点击左侧“项目”右侧的文件夹加号 →“使用现有文件夹”，选择该文件夹。
2. 在该项目中新建会话；也可以点击“新建会话”，再点击输入区的项目名称选择项目。
3. 确认模型为 `gpt-6-sol`，权限选择“请求批准”。
4. 将下方完整示例复制到输入框，点击发送箭头。

```text
请将以下 6 条模拟客户反馈整理成一份简短报告：
1. 包裹比预计时间晚了两天送达。
2. 希望能更及时地更新物流进度。
3. 收到时外包装盒有破损。
4. 包装内缺少缓冲保护材料。
5. 使用说明不够清楚，不知道如何开始。
6. 希望增加一份图文操作教程。
请按物流、包装、使用指导分类，统计每类数量。
每类选取一条典型反馈，并给出改进建议和建议优先级。
请在当前项目的 reports 目录生成 feedback-report.md；目录不存在时先创建。
完成后告诉我文件保存在哪里。
```



### 2.2 确认操作并检查成果

遇到操作确认时，先核对动作与文件位置；符合要求时点击“允许一次”，不符合时点击“拒绝”，再说明需要怎样调整。并非每次写文件都会出现确认卡片。

回复完成后，打开会话中的成果文件，或点击顶部“文件”，查看 `reports/feedback-report.md`。检查三类反馈是否各 2 条，以及每类是否包含典型反馈、改进建议和优先级；有遗漏就在原会话补充要求。

**完成标志：** 报告可以打开，三类反馈各 2 条，包含典型反馈、改进建议和优先级。项目是成果所在的本机文件夹；会话是这次任务的记录。

## 3. 日常协作：补充资料、确认操作和调整任务

### 3.1 把要求说清楚

按“**做什么＋依据哪些资料＋交付什么＋保存在哪里＋有什么限制**”描述任务。例如：“根据本周会议纪要生成一页周报，分为进展、问题和下周计划，保存到 reports，不改动纪要。”继续修改同一份成果时，留在原会话补充要求。

处理自己的资料时，点击输入区 **“＋”（添加上下文）→“添加文件”**，选择资料，等待附件显示后再发送。也可以添加文件夹或技能；图片可拖入输入区或粘贴。发送前核对项目、附件与所选能力；添加文件夹是提供目录路径，不会把整个目录复制成附件。

### 3.2 遇到确认卡片怎样处理

1. 阅读准备执行的动作，必要时展开“查看操作详情”。
2. 核对命令、目录、写入范围或网络目标，确认与任务要求一致。
3. 同意时点击“允许一次”；不理解或范围不对时点击“拒绝”，随后在会话中说明调整要求。



“请求批准”适合新手日常使用；“完全访问权限”会扩大本机操作权限，开启前应确认任务范围。权限选项不代表文件会自动备份或操作可以自动撤销。

### 3.3 任务正在运行时

| 你想做什么 | 操作 |
| --- | --- |
| 补充下一步要求 | 输入补充内容，选择“排队发送”，等待当前运行结束后处理 |
| 优先处理一条等待消息 | 点击等待消息上的“优先执行等待任务”；会停止当前任务后优先处理该消息 |
| 撤回尚未执行的消息 | 点击该消息上的“移除等待任务” |
| 停止当前任务 | 点击“停止任务”，再说明新的处理要求 |
| 离开一会儿再回来 | 从“最近会话”重新打开原任务，检查运行或待确认状态 |

**完成标志：** 补充要求出现在对应会话中，确认后任务继续，或停止后不再继续执行。停止任务不会撤销已经保存的文件或已经完成的外部操作。

### 3.4 让 Clawee 记住你的偏好

记忆用于保存希望长期沿用的表达习惯或工作偏好。在普通会话中，消息包含 **“记住”“以后”“偏好”“始终”“每次”“默认”** 中任意一个词，并且成功发送后，输入框上方会出现 **“保存为长期记忆？”** 确认卡片。

例如，在第 2 节的报告会话中发送：

```text
以后生成报告时，默认先给结论，再列依据。
```

1. 看到确认卡片后，检查预填的记忆内容；可以直接编辑，只保留希望长期沿用的偏好。
2. 选择适用范围。已有会话时默认选择“当前线程”；希望同一项目的其他会话也使用这项偏好时，改为“当前项目”。



| 范围 | 什么时候使用 |
| --- | --- |
| 当前线程 | 只希望当前会话后续任务参考这项偏好 |
| 当前项目 | 希望当前项目中的其他会话也参考这项偏好 |
| 全局 | 希望本机不同项目和会话都参考这项偏好 |

本例可将内容精简为“生成报告时，先给结论，再列依据。”，并选择“当前项目”。



确认内容和范围后点击 **“保存记忆”**。不需要长期保留时点击 **“忽略”**，不会保存，也不影响已发送的任务。若提示内容可能包含敏感信息，先检查内容；仍需保存时，再点击“确认保存”。不要在记忆中保存密码或密钥。

记忆保存在本机，供后续符合范围的任务参考。点击左下角齿轮 →“设置”→“记忆”，可以查找保存的记录并管理，具体操作见第 9.1 节。

**完成标志：** 点击“保存记忆”后确认卡片关闭，在“设置 → 记忆”中可以找到内容与范围正确的记录。

## 4. 找到成果文件与历史会话

### 4.1 查看、修改与保存文件

1. 打开生成成果的原会话，点击成果文件，或点击顶部“文件”。
2. 在文件区选择目标文件，需要时展开目录或筛选文件。
3. 点击“预览”检查内容。可编辑的文本文件可点击“编辑”，修改后点击“保存”。
4. 需要另存一份或用其他软件处理时，点击“下载文件”；桌面端有“打开文件”入口时，可用系统应用打开。



文件区优先展示当前会话的成果；看不到文件时，确认会话与回复中的保存位置。Office 文件等以预览和下载为主，可编辑格式以界面为准。

提示文件“已被外部修改”时，先重新加载并比较内容，再决定是否覆盖。下载得到的是已保存版本，手工编辑后应先保存再下载。

### 4.2 找回并整理会话

- **找最近任务：** 在左侧“最近会话”点击标题，或展开项目选择对应会话。
- **按关键词找：** 点击左侧“项目”行右侧的放大镜“搜索”，输入标题或内容关键词，打开后核对项目和上下文。
- **整理任务：** 在会话更多菜单中选择“重命名”“置顶”或“归档”。标题建议用“客户名＋任务＋日期”。

| 操作 | 对资料的影响 |
| --- | --- |
| 归档会话 | 从活跃列表隐藏，保留历史和项目文件 |
| 永久删除会话 | 删除本地会话及历史记录，不删除项目文件，也不撤销外部操作 |
| 移除项目 | 从 Clawee 项目列表移除，不删除本机文件夹 |

**完成标志：** 可以重新打开正确的会话和成果，文件保存位置清楚，需要的手工修改已保存。

## 5. 使用 Skill

**Skill 是一套可复用的做事方法。** 例如，按公司模板写周报可以使用 Skill。企业 Skill 需组织已开通，且当前账号有权限。

### 5.1 先在 Clawee 对话中创建 Skill

以 **“工作周报助手”** 为例，把“零散工作记录 → 固定格式周报”的方法保存下来，以后每周重复使用，无需提前准备文件。

当前桌面客户端已内置创建技能所需的 `skill-creator`，员工无需另行安装；点击“创建技能”后会自动带入会话输入框。

1. 先点击侧栏“企业Skill”→“企业Skills”→“添加技能”→“创建技能”，进入创建会话。
2. 在输入框已有的技能标记后补充以下需求，点击发送。通过“输入、处理规则、输出格式”把技能要求说清楚：

```text
请帮我创建一个“工作周报助手”Skill，以后每周重复使用。
输入：我粘贴的几条工作记录，无需上传文件。
规则：整理为“本周完成、进行中、遇到的问题、下周计划”四个栏目；
没有提供的信息标注“待补充”，不要编造。输出一份简短的 Markdown 周报。
请先创建包含 SKILL.md 的技能并告诉我如何试用，确认后再打包。
```

3. 创建完成后，在同一会话发送：“请用刚创建的 Skill 整理这三条工作记录：已完成本周资料归档；正在整理下周工作安排；需要同事确认会议时间。”检查是否有四个栏目、记录归类是否合理，缺失信息是否标为“待补充”；需修改时继续说明要求。
4. 试用满意并已登录企业账号后，可在同一会话发送：“请上传刚创建的 Skill，先查询可写技能空间，让我确认空间和版本后再上传。”助手会展示可写空间，等待你明确确认空间及版本，再由客户端打包上传；即使只有一个空间也需确认。上传成功不代表审核通过或已发布。
5. 也可继续使用下一节的手动上传：发送“请将确认好的 Skill 打包为 weekly-report-helper.zip，包含 SKILL.md 及所需文件，保存到当前项目并告诉我文件位置。”到“文件”确认 ZIP 已保存，记住位置供下一步选择。



### 5.2 上传到企业 Skills 中心，选对技能空间

返回“企业Skill”→“企业Skills”，点击“添加技能”→“上传技能”，按以下 **1 至 5** 项依次核对：

1. **技能空间：** 在上传窗口的下拉框中，选择所属部门或本次业务指定的空间。图中“综合办公（演示）”仅作示例，请以实际要求为准。
2. **版本号：** 首次可用 `1.0.0`；后续更新时使用新版本号，避免与已有版本重复。
3. **ZIP 技能包：** 选择上一步生成并试用确认的 `weekly-report-helper.zip`，包内需包含 `SKILL.md` 及所需文件，大小不能超过 50 MB。
4. **更新说明：** 简述用途或本次改动，例如“首次上传：将零散工作记录整理为四栏周报；缺失信息标注待补充”。
5. **上传：** 再次核对技能空间、文件和版本，点击“上传”，等待完成。

**特别提醒：上传窗口可能默认选中第一个可写空间，务必手动核对，不能直接沿用默认值。列表页的“空间”仅用于筛选，不会设置本次上传的归属。找不到指定空间时，请管理员确认授权，不要改选其他空间上传。**



注意：上传成功不代表已通过审核或已发布；需审核时，按页面提示处理，发布可用后再让同事使用。

### 5.3 安装并在任务中使用 Skill

1. 在“企业Skills”中选择目标空间，搜索技能，查看用途、需要的资料和版本；未安装时点击“安装”，有新版时按需“更新”。
2. 点击“使用”，选择项目，再点击“使用所选项目”。
3. 在打开的会话中补充资料和要求后发送，例如：“请用工作周报助手整理以下本周工作记录。”检查成果是否符合要求。



**完成标志：** 自制 Skill 已上传到正确的技能空间，上传记录可核对；已发布的 Skill 能带入会话并生成符合要求的成果。

外部 Skill 先确认来源再安装。

## 6. 使用企业知识库与共享网盘

**查资料用企业知识库，取得或共享文件用共享网盘。** 两者均按账号权限展示。

### 6.1 让 Agent 使用知识库资料

1. 点击侧栏“企业知识库”，选择目标知识库。
2. 确认文档状态为“可用”，需要时选择具体文档缩小范围。
3. 点击“在对话中使用”，选择项目，输入问题。例如：“根据员工手册，说明请假步骤并标明依据；未写明的内容请明确说明。”
4. 检查回答依据，重要规定对照原文核实。

补充资料时，点击“上传文档”（需上传权限），等待状态变为“可用”后使用。

### 6.2 从网盘取得或共享文件

1. 点击侧栏“共享网盘”，确认右上方“当前项目”是本次要使用的项目。
2. 选择共享空间，搜索文件；点击文件行中的“保存到当前项目”，核对保存位置。
3. 遇到同名文件先比较，再决定是否“覆盖保存”；随后回到会话附加文件。
4. 共享本机文件时，进入正确空间，点击“上传文件”。“替换文件”会更新共享版本，提交前确认影响范围。



**完成标志：** 知识库回答有可核对的依据；网盘文件已保存到本机项目，或上传后出现在正确共享空间中。

项目文件在本机，知识库与网盘在企业服务器，**两者不会自动同步**。看不到资源或无法上传时，核对账号并请管理员检查权限。

## 7. 创建与管理定时任务

适合每天整理资料、每周生成回顾等重复工作。先在普通会话中验证任务能完成，再安排定时执行。

### 7.1 创建一个“每日客户反馈汇总”

**练习准备：** 回到第 2 节的原会话，发送“请将上面的 6 条模拟客户反馈原样保存为项目根目录的 feedback.md”，再到“文件”确认已保存。

1. 先确认当前项目是放有反馈资料的项目，再点击侧栏“定时任务”→“创建”。
2. 标题填写“每日客户反馈汇总”，描述中写清资料来源、结果位置和限制，可参考下方示例。
3. 设置重复频率与时间，例如“每天，09:00”；按需选择执行日期。新计划默认使用当前电脑时区。
4. 权限选择“请求批准”，确认“创建后启用”，点击“创建任务”。遇到需确认的操作，任务仍可能等待人工处理。
5. 返回列表，核对启用状态和下一次执行时间。
6. 点击“立即运行”，再点击“查看上次运行”，检查一次真实结果。

```text
读取本项目 feedback.md，按问题分类统计数量。
在 reports 目录生成 feedback-daily.md，注明本次汇总日期。
不要修改原始资料；如果找不到输入文件，请说明原因并停止。
```



### 7.2 后续怎样管理

- **暂停／启用：** 暂停或恢复后续计划触发；暂停不会终止已经开始的运行。
- **编辑：** 修改描述、频率等内容后点击“保存更改”，再次核对下一次运行时间。
- **查看结果：** 打开任务会话查看历次过程和成果，需要调整时在会话中说明要求。
- **删除：** 删除计划前确认不再需要自动执行；已有成果文件不会因此自动删除。

**完成标志：** 下一次执行时间符合预期，“立即运行”能够生成正确结果。执行时电脑需开机、保持唤醒且 Clawee 本地运行服务可用；退出应用或关机后，不能依赖本机继续执行。

## 8. 使用工作台与工作流

### 8.1 在工作台查看 Skill 贡献

1. 点击侧栏“工作台”→“数据洞察”→“Skill 贡献”。
2. 选择“本月”“上月”或自定义日期，按需筛选“审核状态”。
3. 在“上传明细”点击 Skill 名称，查看版本、审核评分和意见；“首次通过”可查看首次通过记录。
4. 需要保存明细时点击“导出 CSV”；完成后点击“返回工作台”。

看不到模块时，请管理员检查权限。“未评分”不等于零分；统计日期和历史覆盖范围以页面提示为准。



### 8.2 发起一个流程任务

1. 点击侧栏“工作流”→“流程模板”。
2. 选择目标模板，阅读步骤和负责人，填写“任务要求”。
3. 点击“发起任务”，到“流程任务”中查看进度。

### 8.3 处理分配给你的节点

1. 进入“待我处理”，打开对应待办。
2. **Agent 执行节点：** 选择执行项目，点击“打开执行会话”，确认模型与权限后发送任务。仅打开会话不会自动执行。
3. 生成结束后检查正文和成果文件，必要时修改，随后点击 **“完成节点并上传结果”**。只有回复生成完毕，节点还没有完成。
4. **审批节点：** 查看上一节点的内容与附件，填写审批意见，选择“批准”或“驳回”。
5. 在执行会话顶部点击“返回流程任务”，核对节点状态与下一步进度。

失败或中断时，点击“继续处理节点”返回会话。发起流程和人工审批无需模型；Agent 执行需模型及本地运行服务可用。

**完成标志：** 正式结果已提交，节点状态更新，流程进入下一步或显示已完成。

## 9. 常用设置与问题处理

### 9.1 常用设置与导出诊断日志

点击左下角齿轮进入“设置”：

| 设置位置 | 怎样使用 |
| --- | --- |
| 常规 | 设置外观、默认权限和关闭窗口行为。新手选“请求批准”；使用定时任务时留意隐藏与退出的区别 |
| 服务器配置 | 核对第 1.2 节的地址；切换服务器前等待任务结束并退出登录 |
| AI模型配置 | 按第 1.3 节核对地址、`gpt-6-sol` 和密钥，检测模型，修改后保存 |
| 记忆 | 搜索、新建、编辑、启用、停用或删除长期偏好，按范围和状态筛选；从会话保存的记忆也在这里管理 |
| 诊断 | 查看本地运行状态和告警；出现问题时按下方步骤导出诊断日志 |
| 关于 Clawee | 查看版本、检查更新，按提示操作 |

**管理记忆：** 在“记忆”页搜索内容，核对范围与启用状态。点击记录右侧的铅笔可编辑内容；“停用记忆”保留记录但停止供后续任务使用，可再启用；“删除记忆”需确认，删除后无法恢复。也可以点击“新建记忆”，填写内容并选择范围后保存。

“全部停用”经确认后会停用 **全部长期记忆**，不受当前搜索或范围筛选限制，记录仍会保留。会话摘要在下方单独列出，需要时可删除对应摘要。



**导出诊断日志：**

1. 点击左下角齿轮 →“设置”→“诊断”。
2. 点击右上角“导出诊断”，在系统保存窗口选择位置，保留默认文件名和 `.json` 格式，点击“保存”。
3. 出现“诊断文件已导出”后，到所选位置确认文件已保存；联系管理员排查时附上该文件。

需要通知时，在系统设置中允许 Clawee 发送通知。



### 9.2 遇到问题先这样处理

| 问题 | 优先检查 |
| --- | --- |
| 钉钉扫码登录失败或连不上服务器 | 核对服务器、网络和扫码授权是否完成；提示无权限时联系管理员 |
| 模型不可用、无法发送 | 到“AI模型配置”核对并检测；到“诊断”检查本地运行服务 |
| 任务很久没有变化 | 查看排队或待确认状态；必要时停止并补充要求 |
| 找不到生成文件 | 回原会话，核对项目和保存位置，打开成果或“文件”区 |
| 企业资源不可用 | 核对账号权限、Skill 安装状态或资料可用状态；请管理员协助检查 |
| 定时任务没有运行 | 检查启用、时间、时区、电脑唤醒状态及待确认操作 |

**联系管理员时提供：** 版本、时间、步骤、错误提示、诊断文件和脱敏截图。遮住密码、API Key 与私人资料；不要删除本地数据尝试修复。
