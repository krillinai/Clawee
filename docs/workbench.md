# 客户端工作台

工作台是桌面端与浏览器端共用的业务能力入口，替代原“数据看板”的展示定位。现有 `dashboard` 导航标识和路由保持不变，兼容已有链接及 Gateway 菜单名称配置。

## 模块组织

- Agent动态：有企业查看权限时显示在工作台首位，进入全屏的团队 Agent 用量与执行概览，可返回工作台；无权限时不显示。
- 数据洞察：业务指标、账号运营等数据分析。当前已接入哔哩哔哩运营看板。
- 内容创作：当前尚未接入模块。
- 素材设计：素材生成与设计能力。

分类按当前可展示模块筛选，没有模块的分类显示空状态。

进入模块详情后隐藏左侧导航，内容区占满可用宽度；移动端同时隐藏导航按钮。通过“返回工作台”回到模块目录后恢复导航，不改变用户原有的侧栏折叠设置。离开工作台时也会清理模块详情状态。

只读模块可以筛选、刷新、查看数据，但不修改业务数据。当前已接入只读的 Agent动态和哔哩哔哩模块，内容创作和素材设计的业务功能尚未实现。

## 模块对话

哔哩哔哩模块采用左侧看板、右侧对话布局，两侧紧邻，由一条可拖动的分割线分隔。拖动分割线可调整两侧宽度，也可聚焦分割线后通过左右方向键调整，Home / End 调整到最小 / 最大对话宽度。对话宽度限制在 320–640 像素，并为看板保留至少 480 像素；窄屏下改用“看板 / 对话”切换，不展示拖拽入口，切换不会关闭会话。打开模块不会自动调用模型；发送问题时才附带当前账号、选定周期、日期范围、指标、趋势和稿件表现快照。切换周期后，下一次提问使用新周期的数据，不改变已经发送的分析。

快照单独通过 `workbenchContext` 传给 daemon，再加入模型执行上下文；会话中的用户消息保持原始问题。不附带其他账号的数据源列表。当前看板加载中、周期或账号不匹配、无可用数据、快照超限或本地 Runtime 未连接时禁止发送。部分数据可以分析，但会携带缺失项信息。旧版服务缺少周期信息时仍可查看看板，但不能发送无法确认范围的快照。

对话复用当前项目下的 daemon 会话、历史记录、流式回复、停止和审批能力，支持选择已配置的模型。发送前会提示看板数据将提供给该模型。会话以 `read-only` 文件系统沙箱创建；此设置不代替企业接口授权，也不新增业务写权限。

当前项目目录不存在或不可访问时，对话禁止发送并显示目录路径，可通过“使用默认项目”调用 daemon 的现有默认项目接口，准备工作目录并切换到该项目。此操作不会自动发送问题，不修改失效项目的路径，也不会恢复丢失的文件；目录问题不应通过“重试连接”处理。

工作台存续期间按模块、企业用户、项目和业务账号绑定会话，返回目录再进入可恢复历史和正在运行的分析；离开模块只断开页面订阅，不取消后台任务。切换账号使用不同会话。完整离开工作台或刷新页面后，模块绑定不会自动恢复，但会话及历史仍保留在当前项目的普通会话列表中。

## 新能力接入

共享入口位于 `client/apps/web/src/features/dashboard/DashboardPage.tsx`。接入新模块时添加模块信息（分类、交互类型、标题和说明），实现对应页面及入口，并补充导航、权限和执行交互测试；无需另加顶层导航。

Web 负责展示与交互，本地执行和持久化仍走 daemon，企业数据和权限仍走 Gateway 的现有接口。分类和“只读 / 可操作”标识不代替服务端授权，新增写操作必须由实际接口校验权限。未来能力的具体配置、接口和执行流程随需求实现，不在工作台中预先建立插件框架。
