# Agent 个人使用统计

Agent 详情页通过 `GET /api/v1/app/activity/agent-usage?collector_id=...&agent_id=...&range=7d` 获取个人统计。接口与 Agent 动态首页使用相同的数据视图读取授权；`range` 支持 `today`、`7d`、`30d`，默认近 7 天，时区为 Asia/Shanghai。

统计使用 `collector_id + agent_id` 精确定位，直接聚合已上报的完整数据，不使用详情列表的条数作为总量。今天按小时、其他范围按天返回趋势，并补齐无活动的时间段。

- 会话、交互轮次、工具调用：按开始时间计入周期。
- 完成轮次：按结束时间计入周期；表示轮次结束，不表示业务任务成功。
- Skill：沿用首页的证据去重口径，按运行和 Skill 去重，区分用户指定、观察到使用、指定后使用和自动使用。排行最多 100 项，总量不受排行上限影响。
- MCP：使用该 Agent 唯一绑定的 MCP 身份及采集来源绑定员工，统计网关允许执行的工具调用。未绑定时返回 `mcp_status=unlinked`，不推测其他身份的调用量。

个人 Token 和模型用量尚无可靠的归属数据源，接口不返回这类数值，客户端显示暂未提供。组织汇总数据不会用作个人数据。

客户端将统计附加到已有详情响应的可选 `usage` 字段。旧网关返回 404，或统计服务临时不可用时，执行记录仍可查看，个人统计显示不可用和刷新入口。401、403、身份或周期不匹配等错误仍按原有授权与协议错误处理。

部署此功能时需要同步更新网关和客户端 daemon；只更新 Web 页面不会让旧网关提供个人统计。
